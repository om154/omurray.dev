
## Raycast

[Raycast](https://www.raycast.com/) is the #1 piece of software I recommend to anyone using a MacBook. I think they even support Windows now too. I use it for all the following and more:

- Calculator
- Clipboard history
- Color picker
- Emoji picker with symbols and AI search
- Hotkeys – global keyboard shortcuts to open any app, e.g. ⌥ + C for Chrome
- Quicklinks – shortcuts for frequently used paths, files, and URLs
- Snippets – text expansion
- Window management – move and resize windows
- Team time – e.g. 🇺🇸 SF / 🇺🇸 NY / 🇮🇹 Italy / 🇺🇾 Uruguay
- Dictation
- AI chats, Quick AI – ⌥ + Space and a chat window is open
- Extensions – there's a marketplace of extensions for almost every single tool you can imagine

Taking the time to setup and learn to use Raycast will save you significant time and will honestly bring you joy throughout the day. The calculator especially is fantastic for making quick calculations when something comes to mind. For example: $100 USD to AUD, or 99°F to °C, "Days until Christmas", "Days until August 29".

## Other software

### VPN

[Mullvad VPN](https://mullvad.net/en) is the most privacy-focused VPN I could find. If you can't use them, try and find at least one that says they keep no logs of your activity. A lot of free VPNs sell your traffic and behavior.

### Password manager

You must use a password manager. Any of these is fine:

- 1Password: very easy and user friendly, $50/year
- Apple's Keychain, on iPhone and Mac with iCloud
- Bitwarden: free
- Proton Pass
- NordPass, which pairs with NordVPN
- `pass`, the Unix utility on the command line. This is what I use, and I back it up manually.

## Keyboard modifications

### Make the trackpad cursor move faster

```sh
defaults write -g com.apple.trackpad.scaling -float 3.0
```

### Speed up the key repeat (optional)

Machine gun backspace.

```sh
defaults write NSGlobalDomain KeyRepeat -int 1
```

### Invert the scroll direction (optional)

```sh
defaults write -g com.apple.swipescrolldirection -bool false
```

### Remove the accent menu when you hold down a key (optional)

```sh
defaults write -g ApplePressAndHoldEnabled -bool false
```
